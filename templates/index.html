    Accepted CSV Format
    
              
            
    
            
    Your CSV file must include a header row with a text column. The system recognizes the following column names and aliases:
    
            
            
    
              
    text (or review, feedback, review_text, SentimentText) [Required]
    
              
    category [Optional, e.g. Support, Product]
    
              
    source [Optional, e.g. Web, Email, Survey]
    
              
    rating [Optional, 1–5 integer]
    
            
    

            
    Encodings supported: UTF-8, UTF-8 BOM, Latin-1. Delimiters: Comma (,), Semicolon (;), Tab (\t), Pipe (|).
